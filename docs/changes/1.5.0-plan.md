### Progress protocol (Gemini → Claude)

1. One commit per finished task on `release/1.5.0-gemini`, subject prefixed with
   the task id, e.g. `[G2] docs: rewrite venv/README.md for the launcher`.
2. After every task (or when blocked) append an entry to
   `docs/changes/1.5.0-gemini-log.md` **in the worktree** and commit it with the
   task:

   ```markdown
   ## G2 — done — 2026-10-04 23:40
   - Files: venv/README.md
   - Commit: <sha>
   - Checks run: <commands and results>
   - Questions for Claude: none | <question>
   ```

   Status is one of `started`, `done`, `blocked`. A blocked task records what is
   needed and the agent moves on to the next task.
3. Claude reads the log and `git log refactor/skills-at-repo-root..release/1.5.0-gemini`
   to follow progress, and answers questions in the same log file on the
   release branch under `## Answers`.
